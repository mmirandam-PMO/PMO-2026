# 📊 Tablero de Control Operativo · PMO 2027

¡Bienvenido! Este repositorio aloja el **Reporte Ejecutivo de la PMO** estructurado de manera modular y exacta a la plantilla nativa de alto rendimiento.

## 🚀 Características Finales
*   **Alineación Original de Columnas:** Respeta las 5 cajas lógicas principales distribuidas de forma exacta en las 3 columnas maestras fijas.
*   **Buscador Multi-Criterio Avanzado:** Permite filtrar instantáneamente en tiempo real por el título de la iniciativa, el nombre del líder responsable o el texto de su estatus actual.
*   **Badges de Estatus Integrados:** Los proyectos integran un indicador cromático visual según su estado real (`En proceso`, `Planeado` o `No planeado`) acoplados directamente al componente meta de la fila.
*   **Insumo Desacoplado Limpio:** La base informativa se gestiona enteramente desde `data.js`.

## 📂 Archivos Generados
1.  `index_html.txt`: Estructura ósea del tablero y contenedores base.
2.  `styles_css.txt`: Identidad visual, gradientes nativos avanzados, tipografía corporativa y badges de estatus.
3.  `data_js.txt`: Base informativa centralizada con los 38 proyectos de la PMO.
4.  `app_js.txt`: Cerebro de filtrado, sanitización de clases de estados y motor de renderizado dinámico.
5.  `readme_md.txt`: Documentación técnica del proyecto.
